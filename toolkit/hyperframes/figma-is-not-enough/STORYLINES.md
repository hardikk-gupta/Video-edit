# Storylines (hyperframes story.md §2): three different films for the same VO

**Recommended: A, "The desk".** A stranger follows it, because it's a real place every designer knows, and the camera
literally shows Figma becoming one small object on a much bigger desk, which is the whole argument.

## A · The desk (recommended)
- **Device + form:** *the object is the explanation*, *a flight through one world*. Top-down over a designer's
  cutting-mat desk. Figma starts full-screen on a laptop, then the camera pulls up and Figma becomes one small object,
  while taste (reference prints), UX judgment (red-pen notes on a printed screen) and the agent (a terminal that builds
  the screen) fill the rest of the desk.
- **First 2 s:** a design canvas fills the frame. A red heart-monitor line runs across it and goes flat on "dead".
  Label tape stamps "ONLY LEARNING FIGMA?".
- **Beats:** flatline hook → Figma Make capture circled in red pen → toolbar buttons fall onto the mat → pull back: the
  laptop is a sketchbook → a chalk head outline on the empty mat → reference prints dealt and one chosen → a printed
  screen marked up in red pen → the marked-up print slides into an agent that builds it → the handoff paper chain
  crumples → this video's own folder, ".fig: 0 results" → the heart line beats again among everything → COMMENT DESIGN
  on label tape.
- **Look:** a green self-healing cutting mat with its grid; paper prints, sticky notes, a silver laptop; Dymo-style
  black label tape for every big line; one accent, red pen.
- **Sound:** paper slides, a label-maker clunk per tape, pen scratches, a shutter as each reference is dealt, the
  monitor beep (flat, then beating). From sfx-kit.

## B · One screen's journey
- **Device + form:** *one object across apps*, *object-to-object chain*. One sign-up screen travels: a pencil sketch →
  a Figma frame → a moodboard → red-pen UX notes → an agent's code → a live phone the viewer taps.
- **First 2 s:** the sign-up screen in Figma. It cracks like glass on "dead".
- **Beats:** sketch → Figma (small) → references → judgment → agent → live app → proof folder → CTA.
- **Look:** a white studio sweep with the screen as the hero object; real UI chrome; one accent.
- **Sound:** UI clicks and swipes, a glass crack, keyboard.

## C · The myth, overprinted (the bold one)
- **Device + form:** *type carries the argument*, *one frame that rebuilds*. A risograph poster: "LEARN FIGMA = DESIGNER"
  printed big, then struck through and overprinted plate by plate with TASTE, JUDGMENT and AGENT, while small real
  screenshots are printed as halftone into the grid.
- **First 2 s:** the poster prints "ONLY FIGMA?" in fluorescent pink over blue, then "DEAD" stamps across.
- **Beats:** the myth printed → struck through → each new skill overprinted → the proof as a halftone folder → CTA plate.
- **Look:** risograph: paper with fibre noise, blue ink A, fluorescent pink ink B, 3 px off-register, halftone dots.
- **Sound:** printer rollers, stamps, paper.

Assumptions: about 46 s, 1080×1920, faceless VO (Hardik records), sfx-kit sound (free, CC0), no paid voice or music.
